# Localhost Manager

Localhost Manager — desktop-приложение для управления локальными проектами и localhost-сервисами в Windows.

## Возможности

- Проекты и несколько localhost внутри каждого проекта
- Запуск, остановка и перезапуск localhost
- Пользовательские команды запуска
- Системный трей
- Избранные localhost
- Уведомления о запуске, остановке и критических ошибках
- Тёмная и светлая темы
- Русский и английский языки
- Запуск вместе с Windows
- Указание порта и URL
- Просмотр логов
- Сохранение проектов и настроек между запусками

## Скачать

Готовая версия для Windows x64 доступна в разделе [Releases](../../releases).

Скачайте архив:

`LocalhostManager-v0.1-win-x64.zip`

Распакуйте архив в удобную папку и запустите `LocalhostManager.exe`.

Приложение собрано как self-contained, поэтому для запуска не требуется отдельно устанавливать .NET 8 Runtime.

## Запуск из исходников

Для работы с исходным кодом требуется:

- Windows 10/11
- .NET 8 SDK
- Visual Studio 2022 или другой совместимый редактор

Клонируйте репозиторий:

```bash
git clone https://github.com/one4sv/LocalhostManager.git
cd LocalhostManager
```

Запустите приложение:

```bash
dotnet run
```

## Сборка

Для Release-сборки:

```bash
dotnet build -c Release
```

Для создания готовой самостоятельной версии Windows x64:

```bash
dotnet publish -c Release -r win-x64 --self-contained true
```

Готовые файлы появятся в:

```text
LocalhostManager/bin/Release/net8.0-windows/win-x64/publish/
```

## Использование

### Создание проекта

1. Нажмите `Добавить проект`.
2. Укажите название и описание.
3. Сохраните проект.

### Добавление localhost

1. Откройте нужный проект.
2. Нажмите `Добавить localhost`.
3. Укажите название.
4. Выберите или добавьте команду запуска.
5. Укажите путь к папке проекта.
6. При необходимости укажите порт и URL.
7. Сохраните localhost.

После этого сервис можно запускать, останавливать и перезапускать непосредственно из приложения.

## Системный трей

В трее доступны:

- проекты;
- localhost;
- избранные localhost;
- запуск всех проектов;
- остановка всех проектов;
- перезапуск всех проектов;
- открытие приложения;
- настройки;
- выход.

Можно назначить до трёх избранных localhost для быстрого доступа.

## Настройки

Доступны настройки:

- запуск приложения вместе с Windows;
- сворачивание в трей при автозапуске;
- отправка закрытого окна в трей;
- тёмная и светлая тема;
- русский и английский язык;
- уведомления о запуске;
- уведомления об остановке;
- уведомления о критических ошибках;
- избранные localhost;
- команды запуска.

## Логи

Для запущенных localhost можно открыть окно логов и просматривать вывод процесса.

## Хранение данных

Проекты и настройки приложения сохраняются локально на компьютере пользователя.

Они не находятся внутри GitHub-репозитория и не включаются в опубликованный ZIP-файл приложения.
